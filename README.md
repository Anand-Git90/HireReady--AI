# HireReady AI

AI Resume + Interview Assistant for career preparation.

## Backend

```bash
cd backend
npm install
npm install multer pdf-parse
npm run dev
```

Runs on `http://localhost:5003`.

## Frontend

```bash
cd frontend
npm install
npm install axios
npm run dev
```

Open the Vite URL shown in the terminal, usually `http://localhost:5173/`.
